# 接收盒实板验收清单

记录接收盒提交号、两份 UF2 文件名、现有发射端版本、主机系统、认证器型号/版本和游戏名。接收盒以 PC XInput 为默认模式。

- [ ] **冷机接线。** 两板单独刷入对应文件，断开所有电源后恢复 SPI、地线和 3V3→BAT。NOLOGO 的 Type-C 留空。确认认证器母座极性、D+/D− 与 5 V。
- [ ] **先测 PC。** 不插认证器，接收 Pico 接 Windows，打开 `joy.cpl`。发射侧断电时应中立；接通原发射组后应看到真实 Hitbox 输入。试快速点按、60 秒长按、双键投、方向帽/摇杆切换。与同一 Hitbox 有线直连作对照。
- [ ] **清零与恢复。** 按住 A 时给发射侧 #1 断电，Windows 手柄应保持枚举，A 应释放。重连时只保留当下仍按住的键。50 ms 是接收端判定时间，用同一时基对齐最后有效无线数据与主机 USB IN 才能测量实际延迟。重启接收盒后重复。
- [ ] **XInput 玩家灯。** 抓取 PC 的 `01 03 mode` OUT，和发射端 Pico 的 `led_out / mode / applied_gen` 或原板 OUT 抓包对照。只有确实收到主机灯命令时才判这一项。
- [ ] **网页与默认脚位。** 用 GP22 接地的维护入口打开网页，核对 USB Host、GP0/GP1、Host USB 和 SOCD Off。保存、撤线、重启，确认设置保留。[接线与菜单步骤](WIRING_AND_PS_AUTH.md)
- [ ] **PS4 与 PS5 分开验收。** 每次先选择对应模式，插入实体认证器，连接目标主机。从系统菜单进入支持的游戏，持续操作至少 10 分钟。记录枚举、方向、组合键和是否掉线；替换认证器或游戏时单独记录。
- [ ] **其他目标模式。** Switch 模式在 Switch 主机开启对应有线控制器选项后测试；Xbox One 使用兼容认证器测试。每个平台单独记录通过或失败，保留主机侧现象、时间点及抓包。
